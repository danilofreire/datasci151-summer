Jupyter Notebook and Markdown

Introduction

This tutorial introduces Jupyter Notebook and Markdown. Jupyter Notebook lets you write documents that mix live code, equations, plots and text. Markdown is a simple way to format text, and people use it for websites, notes, books, presentations, emails and technical documentation. WhatsApp uses a similar syntax too, so if you have ever made a word bold or italic on WhatsApp, you have already used something very close to Markdown!

The tutorial has two parts. The first part shows you how to create a notebook, run code cells and write text cells. The second part covers Markdown in more detail: headings, lists, tables, equations, figures and footnotes.

Introduction to Jupyter Notebook

What is Jupyter Notebook?

Jupyter Notebook is free, open-source software for writing documents that combine code, equations, plots and text. It supports over 40 programming languages, including Python, R and Julia, and it is very popular in data science, machine learning and scientific computing.

A notebook is made of cells. Each cell contains either code or text, and when you run a code cell you see the result right below it. You can run one cell at a time or the whole notebook. Notebooks are saved as .ipynb files, which you can share with others so they can reproduce your analysis.

Creating a new notebook

First, please make sure you have Anaconda and VS Code installed on your computer. If you have not installed them yet, Tutorial 01 shows you how.

To create a new notebook in VS Code, go to “File” > “New File”. A prompt will appear in the middle of the screen. Select “Jupyter Notebook”.

VS Code will create a new notebook with the .ipynb extension. You can give it a name when you save it. An empty notebook looks like this:

Please do not forget to select the Python version the notebook should use (Jupyter calls it the “kernel”). Click on “Select Kernel” at the top right corner of the screen and choose Anaconda’s “base” environment.

To add a code cell, click on “+ Code”. You will see an empty grey box with “Python” in the lower-right corner. Type your Python code in the box and run it by clicking on the “Run” button on its left, or by pressing Shift + Enter.

For example, type the following code in the cell:

print("Welcome to DATASCI 151!")

x = 5
y = 10
z = x + y
print(z)

The result appears right below the cell:

To add a text cell, click on “+ Markdown”. You will get an empty box where you can type text. We will see Markdown in more detail in the next section, but for now, type the following text in the cell:

This is a Jupyter Notebook. You can write *text*, **equations**, and `code` 
in [this notebook](https://github.com/danilofreire/datasci151-summer/blob/main/tutorials/testing-ipython.ipynb).

Introduction to Markdown

Why use Markdown?

Markdown is simple, easy to learn and supported almost everywhere. With a few symbols you can add headings, lists, tables, equations and figures to your documents. Jupyter Notebook, GitHub and Slack all use Markdown, so you will use what you learn here in many other places.

Headings

Use the # symbol for headings. # Heading 1 creates a first-level heading, ## Heading 2 a second-level heading, and so on, up to six levels.

# Heading 1
## Heading 2
### Heading 3

Lists

This is how you write a numbered list with bullet points inside it:

1. This is an ordered list.
2. This is the second item in the ordered list.
  - This is a sub-item in the unordered list.
    - This is a sub-sub-item in the unordered list.
  1. This is an ordered list.
  2. This is the second item in the ordered list.
    • This is a sub-item in the unordered list.
      • This is a sub-sub-item in the unordered list.

And this is a bullet-point list:

- This is an unordered list.
- This is the second item in the unordered list.
  - This is a sub-item in the unordered list.
  • This is an unordered list.
  • This is the second item in the unordered list.
    • This is a sub-item in the unordered list.

Tables

Use the | symbol to separate the columns of a table. For example:

Table: Your Caption 

| A            | New              | Table          |
|:-------------|:----------------:|---------------:|
|left-aligned  |centre-aligned    |right-aligned   |
|*italics*     |~~strikethrough~~ |**boldface**    |
Your Caption
A New Table
left-aligned centre-aligned right-aligned
italics strikethrough boldface

The colons in the second row set the alignment of each column. A colon on the left (:---) aligns the text to the left, colons on both sides (:---:) centre it, and a colon on the right (---:) aligns it to the right.

Creating Markdown tables from pandas DataFrames

You can also turn a pandas DataFrame into a Markdown table, which often looks nicer in a report. Here is how to do it.

Prerequisites

You will need:

  1. Jupyter Notebook
  2. pandas
  3. tabulate (for enhanced table formatting)

Jupyter Notebook and pandas come with Anaconda. You can install tabulate with conda install in the terminal. In VS Code, open a terminal by clicking on “Terminal” > “New Terminal” in the top menu, then run:

conda install tabulate

The basic method: pandas.DataFrame.to_markdown()

pandas has a built-in method, to_markdown(), that converts a DataFrame into a Markdown table.

Step 1: import pandas and create a DataFrame

Create a DataFrame by passing a dictionary to pd.DataFrame():

# If necessary, install pandas and tabulate 
# You should have pandas installed if you installed Anaconda, 
# but if you do not, you can install both with the following terminal command:
# conda install pandas tabulate

# Import pandas
import pandas as pd
from tabulate import tabulate

# Create a sample DataFrame
data = {
    "Name": ["Alice", "Bob", "Charlie"],
    "Age": [25, 30, 35],
    "City": ["New York", "London", "Paris"]
}
df = pd.DataFrame(data)

Step 2: convert the DataFrame to Markdown

Then call to_markdown() on the DataFrame:

# Print the DataFrame as a Markdown table, excluding the index
markdown_table = df.to_markdown(index=False)
print(markdown_table)

This will output:

| Name    | Age  | City     |
|:--------|-----:|:---------|
| Alice   |   25 | New York |
| Bob     |   30 | London   |
| Charlie |   35 | Paris    |

Step 3: display the table in the notebook

To show the table as formatted Markdown, use the display() function from the IPython.display module:

# You should also have the IPython package installed if you installed Anaconda
# If not, you can install it with
# conda install ipython

# Import the Markdown display class. 
# This is what allows us to display Markdown in Jupyter Notebooks 
from IPython.display import display, Markdown

# Display the Markdown table
display(Markdown(markdown_table))

The notebook will show a formatted table:

More formatting options

to_markdown() has several arguments that change how the table looks:

# Customising the Markdown table using the to_markdown() method
markdown_table = df.to_markdown(
    index=False,  # Don't include index
    tablefmt="pipe",  # Use pipe format
    floatfmt=".2f",  # Format floats to 2 decimal places
    headers=["Name", "Age (Years)", "City"],  # Custom headers
    colalign=("left", "center", "right")  # Align columns
)
display(Markdown(markdown_table))

Using tabulate

The tabulate library has even more formatting options. You will probably not need them in our course, but I include an example here in case you want to try them. Please see the tabulate documentation for more information.

from tabulate import tabulate

markdown_table = tabulate(df, headers='keys', tablefmt='pipe', showindex=False)
display(Markdown(markdown_table))

Tips

  1. You often do not need the index (the row numbers), so remove it with index=False
  2. Use floatfmt to set the number of decimal places
  3. Rename the headers if your column names are hard to read
  4. Try different tablefmt options to see which one you like best
  5. For large DataFrames, show only some of the rows or columns so the table stays readable

A complete example

Here is an example that uses several of these tips:

# Import necessary packages
import pandas as pd
from IPython.display import display, Markdown
from tabulate import tabulate

# Create a sample DataFrame
data = {
    "Product": ["Laptop", "Smartphone", "Tablet"],
    "Price": [999.99, 599.50, 299.75],
    "Stock": [50, 100, 75],
    "Rating": [4.5, 4.8, 4.2]
}
df = pd.DataFrame(data)

# Create a formatted Markdown table
markdown_table = tabulate(
    df,
    headers=["Product Name", "Price ($)", "Stock Quantity", "Customer Rating"],
    tablefmt="pipe", # Format as Markdown table
    floatfmt=(".2f", ".2f", "d", ".1f"),
    showindex=False, # Don't show the index (row numbers)
    numalign="right", # Align numbers to the right
    stralign="left" # Align strings (text, first column) to the left
)

# Display the table in the notebook
display(Markdown("### Product Inventory Summary"))
display(Markdown(markdown_table))

The result is a table with a title, custom headers and formatted numbers.

Equations

Write equations between two $$ symbols. For example, here is the formula for the standard deviation of a population:

$$
\sigma = \sqrt{\frac{\sum_{i=1}^{N} (x_i - \mu)^2}{N}}
$$

\[ \sigma = \sqrt{\frac{\sum_{i=1}^{N} (x_i - \mu)^2}{N}} \]

For an equation inside a sentence, use a single $. For example, $\alpha = \beta + \gamma$ becomes \(\alpha = \beta + \gamma\). Equations use LaTeX syntax, and the Overleaf documentation lists the symbols you can use.

Figures

To add a figure, use the ![Caption](path/to/image.png) syntax. For example:

![This is a figure caption.](path/to/image.png)

This adds the image path/to/image.png to your document, with the caption “This is a figure caption.”

Plots you create with Python appear automatically below the code cell that makes them.

Citations

Tools such as Quarto can create citations automatically from BibTeX files, but there is no reliable way to do this in Jupyter Notebooks. The two packages I know, cite2c and JupyterLab Citation Manager, are not ideal: the first has not been maintained for years, and the second is not ready for most uses. So I suggest you copy each citation from Google Scholar and paste it into a Markdown cell called “References” at the end of your notebook. You can write inline citations by hand too, such as “(McKinney, 2022)”.

Footnotes

Markdown also supports footnotes1. To add one, write a caret and a label inside square brackets where the footnote number should appear, like this: [^label]. Then write the footnote text anywhere in the document, starting with the same label and a colon2. I usually put them right after the paragraph. The footnotes are numbered automatically.

Footnotes are part of extended Markdown. They work in Quarto documents and on GitHub, but some notebook programs do not display them, so please check how they look before you use them in a notebook.
