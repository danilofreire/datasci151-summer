Installing VS Code and connecting it with Anaconda

Introduction

This tutorial shows you how to install Visual Studio Code (VS Code) and Anaconda, and how to connect the two. It is written for students who have never programmed before, so we will go through each step slowly. If you have any questions or run into problems during the installation, please email me at danilo.freire@emory.edu and I will be happy to help.

Why VS Code?

VS Code is a free code editor developed by Microsoft. In the 2025 Stack Overflow Developer Survey, about 76% of respondents said they use VS Code, more than any other editor. Here are some reasons why we use it in this course:

  • It has many built-in features, such as syntax highlighting, code completion and debugging, and thousands of extensions that add more
  • It works on Windows, macOS and Linux, so everyone in class can follow the same steps
  • It has a large community, so it is updated often and you can easily find help online
  • It works well with Git and GitHub (Microsoft owns GitHub), which we will use to manage the course materials

Let us start with the installation.

Download and install VS Code

  • Go to the official VS Code website: https://code.visualstudio.com/
  • Click on the “Download” button for your operating system (Windows, macOS or Linux)

Windows

  • Run the VSCodeUserSetup-{version}.exe file you downloaded
  • Accept the licence agreement and click “Next”
  • Choose the installation folder (the default is fine) and click “Next”
  • Select any additional tasks you want, such as adding an “Open with Code” option to the right-click menu, and click “Next”
  • Click “Install”

macOS

  • Open the .zip file you downloaded and drag the VS Code application to your Applications folder

Linux

  • Follow the instructions for your distribution on the VS Code website

Open VS Code

  • Open VS Code after the installation
  • You should see a welcome screen with options to start a new project or open existing files

Microsoft has a series of introductory videos that will help you get started with VS Code. The official documentation has more details if you need them.

Installing Anaconda

Anaconda is a distribution of Python that already includes many of the packages we use for data science, such as pandas, NumPy and Jupyter. It also helps you manage different Python environments (see Tutorial 04). Anaconda is free for students and for teaching at universities.

Download Anaconda

  • Go to the Anaconda website: https://www.anaconda.com/download. You can skip the registration if you prefer
  • Click on the “Download” button for your operating system

Windows

  • Choose “Just Me” as the installation type (recommended)
  • Select the installation folder (the default is fine)
  • In “Advanced Options”, keep “Register Anaconda as my default Python” ticked. Anaconda recommends that you do not tick “Add Anaconda to my PATH environment variable”, so please leave that box empty. Your screen may look slightly different from the image below, depending on the version you download

macOS

  • Open the .pkg file you downloaded and follow the installation instructions. You can install Anaconda for all users
  • Accept the default options on each screen

Linux

  • Follow the instructions for Linux on the Anaconda website

Check that Anaconda works

  • Open a terminal. On Windows, use the “Anaconda PowerShell Prompt” from the Start menu. On macOS, you can open a terminal inside VS Code by clicking on “Terminal” > “New Terminal” in the top menu
  • Type conda --version and press Enter. You should see the conda version number
  • Type python --version and press Enter. You should see the Python version that came with Anaconda

If macOS says conda: command not found, run conda init zsh once in the terminal, then close and open the terminal again. We will see more about the terminal and conda in Tutorial 04.

Connecting VS Code with Anaconda

Now that you have installed VS Code and Anaconda, we will tell VS Code to use Anaconda’s Python. If everything works, you will see the Python version from Anaconda in VS Code’s terminal.

Install the Python and Jupyter extensions

  • Open VS Code and click on the Extensions icon on the left sidebar (it looks like four squares). Search for “Python”
  • Find the official Python extension by Microsoft and click “Install”
  • Then install the Jupyter extension, which lets you work with Jupyter Notebooks in VS Code

Select Anaconda’s Python

  • Create a new file in VS Code. Click on “File” > “New File” and save it with a .py extension
  • Add the following code to the file:
import sys
print(sys.version)
print(sys.executable)
  • Save the file again. I saved mine as testing-anaconda.py
  • Press Ctrl+Shift+P (Windows/Linux) or Cmd+Shift+P (macOS) to open the Command Palette
  • Type “Python: Select Interpreter” and select it from the list
  • Choose Anaconda’s Python from the list. It should be called something like “Python 3.x.x (‘base’)” and mention conda

Check the connection

  • Click on the “Run” button at the top right corner of the editor and select “Run Python File in Dedicated Terminal”
  • The output should show Anaconda’s Python version and the folder where it is installed

Optional: GitHub Copilot

GitHub Copilot is an AI assistant that suggests code as you type and answers questions in a chat window. It is built into VS Code, so you do not need to install a separate extension.

  • Hover over the Copilot icon in the Status Bar at the bottom of VS Code and select “Use AI Features”
  • Sign in with your GitHub account. If you do not have a Copilot plan, VS Code will sign you up for Copilot Free, which gives you a limited number of suggestions and chat messages each month
  • As a student, you can also get Copilot Student for free. Verify your student status on GitHub Education first (see Tutorial 03)
  • Once you are signed in, Copilot will suggest code as you type. Press Tab to accept a suggestion. You can also open the chat window and ask questions in plain English, as you would with ChatGPT or Claude

The VS Code documentation has more details on how to set up Copilot.

Copilot is very helpful, but it also makes mistakes. Please always check its suggestions before you use them. And remember that AI tools are not allowed during quizzes!

Conclusion

You have now installed VS Code and Anaconda and connected them. Well done! :)
